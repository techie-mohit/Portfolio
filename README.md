
# Portfolio Website

This is a personal portfolio website built with **React** and **Vite**. It showcases your skills, experience, education, projects, and contact information in a modern, responsive design. The site is deployed on Vercel for fast and reliable access.

---

## 🚀 Live Demo

**View the deployed site:** [https://portfolio-techie-mohits-projects.vercel.app/](https://portfolio-techie-mohits-projects.vercel.app/)

## 🛠️ Technologies Used

- **React**: UI library for building interactive interfaces
- **Vite**: Fast build tool and development server
- **JavaScript**: Main programming language
- **CSS**: Styling and layout
- **ESLint**: Code linting and quality
- **Vercel**: Deployment platform

---

## ✨ Features

- **Modern, Responsive UI**: Works on desktop and mobile
- **Multiple Sections**: About, Education, Work Experience, Tech Stack, Projects, Contact
- **Reusable Components**: Navbar, Buttons, Cards, etc.
- **3D Models**: GLB files for interactive visuals
- **Social Media Integration**: Icons and links
- **Organized Assets**: Images, logos, and media in dedicated folders
- **Fast Development**: Hot module replacement with Vite
- **Code Quality**: ESLint for consistent code

## 🏃‍♂️ Getting Started

1. **Clone the repository:**
	```sh
	git clone https://github.com/techie-mohit/Portfolio.git
	cd portfolio
	```
2. **Install dependencies:**
	```sh
	npm install
	```
3. **Start the development server:**
	```sh
	npm run dev
	```
4. **Build for production:**
	```sh
	npm run build
	```
5. **Preview production build:**
	```sh
	npm run preview
	```
